==================================================
PROJECT TITLE: FreshCart - Online Grocery System
==================================================

PROJECT OVERVIEW:
FreshCart is a responsive, client-side web application designed for browsing, filtering, and ordering everyday groceries. The frontend is built using standard semantic HTML5, modern CSS3 styling, Tailwind CSS utility classes, and vanilla JavaScript (ES6+).

FEATURES:
1. Product Catalog: Categorized grocery items (Produce, Dairy, Bakery, Beverages, Snacks, Household).
2. Live Search & Category Filtering: Dynamic search by name/category with instant DOM rendering.
3. Interactive Slide-out Cart: Add/remove items, adjust quantity, dynamic total and free shipping calculation (threshold ₹499).
4. Checkout & Form Validation: Validates Indian mobile numbers (regex: [6-9][0-9]{9}) and delivery address.
5. Simulated Order Submission: Simulates order placement workflow with feedback and order summaries.

PROJECT STRUCTURE:
- index.html               : Main markup and layout
- style.css                : Custom styles, layout variables, and animations
- app.js                   : Application state, cart operations, search/filter algorithms
- README.txt               : Project documentation
- Viva_Questions.txt       : Exam/Viva preparation guide
- Project_Report.docx      : Comprehensive project documentation
- Project_Presentation.pptx: Presentation slides for project evaluation

HOW TO RUN:
1. Double-click "index.html" to open it in Google Chrome, Edge, or Firefox.
2. OR open the folder in Visual Studio Code and launch via the Live Server extension.
